# AI Use Explanation

AI tools were used during the development of this project to help improve the program structure, user interface design, debugging process, and documentation.

The original version of the project was created as a basic text-based financial simulation game using Python. After creating the starter version, AI assistance was used to help expand the project into a more advanced graphical game using Tkinter.

AI assistance helped with:
- Improving the graphical user interface
- Adding additional gameplay features
- Debugging runtime and JSON errors
- Improving code organization
- Expanding documentation files
- Adding animations and progression systems

All code was reviewed, tested, modified, and understood before submission. I made changes throughout the development process and learned how to improve Python programming structure, GUI design, file handling, and game logic.

Through this project, I learned:
- How to build GUI applications using Tkinter
- How JSON files can save and load data
- How object-oriented programming works using classes
- How randomness and probability can be used in games
- How to organize larger Python projects

The final project reflects both my own work and the use of AI as a development and learning assistant.
